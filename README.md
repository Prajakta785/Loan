## 🌟 प्रमुख वैशिष्ट्ये (Key Features)

### 1. ग्राहक वेबसाईट (Customer Portal)
- **द्विभाषिक सुविधा (Bilingual Toggle):** मराठी (मराठी) आणि English मध्ये एका क्लिकवर संपूर्ण वेबसाईट अनुवादित होते.
- **हिरो सेक्शन (Hero Section):** थेट EMI प्रिव्ह्यू, रिअल-टाइम कॅल्क्युलेशन, 24 तासांत मंजुरी बॅज आणि आकर्षक व्हिज्युअल्स.
- **6 प्रमुख कर्ज योजना (Loan Products):**
  1. **Personal Loan (वैयक्तिक कर्ज)** - 10.5% p.a. विनातारण
  2. **Home Loan (गृह कर्ज)** - 8.4% p.a. 30 वर्षांपर्यंत
  3. **Business Loan (व्यवसाय कर्ज)** - 11.2% p.a. खेळत्या भांडवलासाठी
  4. **Agriculture / Kisan Loan (शेती कर्ज)** - 7.0% p.a. 7/12 उताऱ्यावर
  5. **Gold Loan (सुवर्ण कर्ज)** - 8.9% p.a. 30 मिनिटांत
  6. **Vehicle Loan (वाहन कर्ज)** - 8.7% p.a. 100% ऑन-रोड फायनान्स
- **स्मार्ट EMI कॅल्क्युलेटर:** मुद्दल (Principal) vs व्याज (Interest) चे SVG डोनट चार्टसह रिअल-टाइम ब्रेकडाउन व हप्ता नियोजन.
- **झटपट पात्रता तपासणी (Eligibility Checker):** मासिक उत्पन्न व सध्याचे हप्ते टाकून कमाल कर्ज मर्यादा तपासणे.
- **5-पायरी ऑनलाइन अर्ज फॉर्म (5-Step Application Wizard):**
  - वैयक्तिक माहिती (नाव, मोबाईल, शहर)
  - केवायसी तपशील (आधार, पॅन प्रमाणीकरण)
  - रोजगार व उत्पन्न (वेतनधारक, व्यावसायिक, शेतकरी)
  - कर्जाची मागणी व उद्देश
  - कागदपत्रे अपलोड सिम्युलेटर (Aadhaar, PAN, Bank Statement)
  - **कन्फेटी सेलिब्रेशन (Confetti), युनिक अर्ज क्रमांक (उदा. `ML-2026-8012`) व पावती प्रिंट/डाऊनलोड.**
- **अर्ज स्थिती ट्रॅक करा (Live Status Tracker):**
  - अर्ज क्रमांक किंवा मोबाईल नंबर टाकून 5-टप्प्यांची प्रगती बार (Progress Timeline) तपासणे.
  - ॲडमिन कडून पाठवलेला रिअल-टाइम शेरा (Remarks) ग्राहकाला थेट दिसतो.
- **संपर्क व व्हॉट्सॲप थेट चॅट:** फ्लोटिंग व्हॉट्सॲप आणि पुणे/महाराष्ट्र शाखा संपर्क.

---

### 2. शक्तिशाली ॲडमिन पॅनल (Admin Control Panel)
- **एका क्लिकवर स्विच:** वरच्या उजव्या कोपऱ्यात किंवा फ्लोटिंग बटनावर क्लिक करून ग्राहक व ॲडमिन मोडमध्ये स्विच करता येते.
- **डॅशबोर्ड केपीआय (Dashboard KPIs):** एकूण अर्ज, प्रलंबित (Pending), मंजूर (Approved), वितरित (Disbursed), नामंजूर (Rejected), एकूण वितरित भांडवल.
- **कर्ज प्रकारानुसार प्रमाण चार्ट:** व्हिज्युअल बार व टक्केवारी.
- **अर्ज व्यवस्थापन (Applications Management):**
  - सर्च (नाव, मोबाईल, पॅन, शहर किंवा अर्ज क्र.)
  - फिल्टर टॅब्स (All, Pending, Approved, Disbursed, Rejected)
  - **तपासणी व मंजुरी ड्रॉवर (Review & Action Drawer):**
    - अर्जदाराची संपूर्ण माहिती व केवायसी तपासणी
    - अर्ज स्थिती बदलणे (मंजूर, वितरित, नामंजूर)
    - मंजूर रक्कम (Sanctioned Amount) व व्याजदर कस्टमाईज करणे
    - ग्राहकासाठी ॲडमिन शेरा (Admin Remarks) जोडणे
- **ग्राहक निर्देशिका (Customer Directory):** सर्व अर्जदारांची प्रोफाईल व एकूण अर्ज संख्या.
- **हप्ते व वाटप ट्रॅकर (EMI & Disbursements):** सक्रिय कर्जांचे हप्ते व देय तारखा.
- **CSV डेटा एक्सपोर्ट:** एका क्लिकवर सर्व अर्जांचा डेटा एक्सेल/CSV मध्ये डाऊनलोड.
- **डेमो डेटा रीसेट:** एका क्लिकवर नमुना अर्ज पूर्ववत करण्याची सुविधा.

## 🛠️ तंत्रज्ञान (Technology Stack)
- **Frontend:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 + Plus Jakarta Sans + Noto Sans Devanagari
- **चिन्हे (Icons):** Lucide React
- **अॅनिमेशन व इफेक्ट्स:** Canvas Confetti, Smooth Scroll, Modern Fintech Gradient Glows
- **डेटा साठवणूक:** LocalStorage (डेटा सुरक्षित राहतो आणि रीफ्रेश केल्यावरही जात नाही)
